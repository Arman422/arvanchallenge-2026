# FrontEnd Developer Challenge

# داشبورد یکپارچه مدیریت قطعه کد

در این چالش، شما باید رابط کاربری یک داشبورد را برای نوشتن و مدیریت قطعه کدها پیاده‌سازی کنید و با نوشتن یک API ساده در همان بستر فرانت‌اند، چرخه رفت و برگشت داده را کامل کنید.

## نیازمندی‌های رابط کاربری (Front-end)

### یکپارچه‌سازی ویرایشگر کد

استفاده از پکیج‌هایی مانند **Monaco Editor** یا **CodeMirror** در داخل رابط کاربری برای فراهم کردن امکان کدنویسی با Syntax Highlighting.

### مدیریت وضعیت پیشرفته (State Management)

کاربر باید بتواند چند فایل یا تب مختلف را باز کند و با جابجایی بین آن‌ها (بدون ذخیره در دیتابیس)، کدهای نوشته‌شده از بین نرود.

### شبیه‌سازی کنسول خروجی

طراحی یک بخش در پایین صفحه برای نمایش خروجی کدهای اجرا شده (متن موفقیت یا خطا) با طراحی مشابه ترمینال‌های استاندارد.

---

## نکاتی درباره پیاده‌سازی

نیازی به راه‌اندازی دیتابیس یا سرور مجزا نیست. از شما انتظار می‌رود با استفاده از امکانات سمت سرور فریم‌ورک خود (مانند `server/api` در Nuxt 3 یا ابزارهای مشابه)، صرفاً یک Endpoint ساده (**Mock API**) بنویسید که کارهای زیر را انجام دهد:

### اعتبارسنجی اولیه

کد ارسال شده از سمت کلاینت را دریافت کرده و بررسی کند که ساختار Payload درست باشد و بدنه کد خالی نباشد.

### شبیه‌سازی شبکه و پردازش

یک تأخیر (Delay) عمدی **۲ الی ۳ ثانیه‌ای** ایجاد کند تا مهارت شما در مدیریت Loading State و غیرفعال کردن دکمه‌ها در سمت فرانت‌اند سنجیده شود.

### تولید پاسخ تصادفی

به صورت رندوم، در **۸۰٪** مواقع یک پاسخ موفقیت‌آمیز مثل:

```json
{"status": "success", "output": "Hello World"}
```

و در **۲۰٪** مواقع یک خطای سرور برگرداند تا نحوه نمایش Error Handling در UI بررسی شود.

## خروجی‌ها و مستندات مورد انتظار

- کد تمیز و ساختاریافته در یک ریپازیتوری (Github/Gitlab) به همراه کامیت‌های معنادار.
- فایل `README.md` شامل دستورالعمل راه‌اندازی پروژه و توضیح کوتاه در مورد نحوه پیاده‌سازی Mock API.
- طراحی واکنش‌گرا (Responsive) برای استفاده در تبلت و دسکتاپ.
