# Browser-persisted snippet list with cross-tab write-through

The snippet list is the durable unit of work: it is written to same-origin browser storage and kept in sync across tabs. Console history, active snippet, panel chrome, and run lock stay tab/session-local. Edits still bind directly to snippet state with no save button and no dirty indicators — automatic write-through (debounced for code; immediate for create/rename/delete). Other tabs are notified and quietly replace their in-memory list; if the active id disappeared they deselect, otherwise they adopt the winning fields. Conflict policy is whole-list last-write-wins. That matches single-user sequential tab use (a human tab-switch is slow enough that the other tab has already adopted); overlapping same-moment mutations across tabs are accepted as negligible. Manual save/sync and per-snippet merge were rejected as they reintroduce a persistence boundary or add complexity without matching the Obsidian-like model. Scope is same browser profile and origin only — not cross-device or a backend database.
