# Monaco language scope and diagnostics ceiling

Snippets are multi-language: a curated allowlist (Plain Text, JavaScript, TypeScript, JSON, HTML, CSS, Less, SCSS, Markdown, YAML, XML, Python, Go, Rust, Java, C, C++, C#, SQL, Shell, Dockerfile) gets syntax highlighting via Monaco’s built-in tokenizers. Error highlighting is only enabled for languages Monaco validates out of the box (JavaScript/TypeScript, JSON, CSS/Less/SCSS, HTML/Handlebars/Razor); other allowlisted languages stay highlighting-only permanently unless we deliberately revisit. Editor suggestions stay off. Language is chosen after create (default JavaScript) via the editor-zone control, not on “+ New Snippet.” Full language servers / LSP for the rest were rejected as out of scope for a lightweight snippet pad.
